# 給簡報產生器 session 的指令：三個變數的「註冊區間 → 各區間的意思」

（Adam 2026-09-02 交辦；接在 `PROMPT_how-we-measured-diagram.md` 那張關卡帶之後。）

---

`How we measured` 那張關卡帶做得好，這張是它的下一頁：**把「預註冊」從一個承諾變成一張看得懂的圖**。

**要傳達的一件事**：出手前我們把每個變數的**結果空間切成幾段，每一段預先寫好它代表什麼**——
所以沒有「實驗失敗」這個選項，只有「落在哪一段」。**三段都是結果，不是只有一段是。**

**做法**：一個變數一張圖（共三張，可並排成一頁，也可各自一頁——你依 §C0-v2 頁序決定）。
每張圖＝**一條數線**，上面標出註冊的切點、每段的名字與意思、以及**實測值落在哪裡**。
先讀 `NDTwin-slide-template-903.md` 的 §C0-v2 與 §C''，確認插在哪、不要跟 p.8 的 band 重複。

## 資料（逐字取自預註冊檔，**不要改動、不要自己算**）

### 圖 A — Build：比值 R
正本 `doc/audit/2026-08-28_single-switch-build-ratio/PREREG.md:69–73`

| 段 | 區間 | 註冊的意思（原文照譯，圖上只放短版） |
|---|---|---|
| H2 | **R < 9** | 部分來自三跳路徑與其上的活控制平面，**不是**來自 build ⇒ 論文那句話要改寫 |
| H1 | **R ∈ [9, 20]** | 12× 通過隔離，論文可以說「這個 build 快約 12 倍」 |
| H3 | **R > 20** | 三跳上有別的東西在限制 bmv2-fast ⇒ 12× 是**下界** |

實測：**R = 8.0**（落在 H2），量化區間 **(5.14, 12.0)**——**它跨過 9 這個切點**。
第二台機器 **(3.27, 7.71)**，與 machine 1 的區間相交。
🔴 **這張圖的重點就是那個跨界**：實測值落在 H2，但它的不確定區間同時蓋住 H1。
畫法＝實測用一個**帶誤差橫條的點**，橫條要明顯地騎在 9 上面。旁邊一行小字 `a decision-rule gap we disclose`。

### 圖 B — Size：比值 P(1024)/P(64)
正本 `doc/audit/2026-08-28_packet-size-sweep/PREREG.md:79–90`

| 段 | 區間 | 意思 |
|---|---|---|
| H2 — bandwidth-limited | **[0.03, 0.12]** | 頭條**對這個 build 是錯的**，論文必須說天花板是 bps |
| H3 — mixed cost | H1 與 H2 **之間**的任何值 | **是結果，而且可能是最有意思的那個**：成本可拆成固定的每封包項與每位元組項 |
| H1 — per-packet cost | **[0.65, 1.30]** | 頭條成立，報 pps 恆定與殘差 |

實測：**1.00**（H1 內），另一個比值 P(256)/P(64) 也在其 H1 區間 **[0.75, 1.30]** 內。
🔴 圖上要讓 H3 那段**看起來跟另外兩段一樣正式**（同樣的框、同樣的字重）——
它是預先註冊的第三種結果，不是「沒結論」。這是這張圖唯一的論點。

### 圖 C — Flows：n=2 的總量（Mbit）
正本 `doc/audit/2026-08-28_flow-count-capacity/PREREG.md:70–77`；放棄判準在 `HANDOFF-CONTEXT.md:65–67`（commit `48487ed`，資料之前）

註冊區間：**n=2 → 95–150**（n=4 → 65–125；n=8 → 45–90；n=16 → 35–70）
放棄判準逐字：**「if n=2 lands outside 95–150 in both arms … Stop and re-derive.」**
實測：**兩臂都是 220.0** ⇒ **判準發火，這一輪不得報告成「測試了那些區間」**。

🔴 這張圖跟前兩張形狀不同，**不要畫成「又一個落點」**：
畫一條數線、95–150 的註冊帶、220 這個點**明顯落在帶子外面**，然後一個標記說 `ABANDON RULE FIRED`。
下方一行：`the model that generated every interval was wrong — the curve stands, the intervals do not`。
**不要**把 n=4／n=8／n=16 的區間畫上去（那些區間已經作廢，畫了會誤導）。

## 硬性限制

- **圖上字要少**：變數名、切點數值、每段一個短標籤、實測點。**「意思」欄只放三到五個字的短版**，
  完整句子寫講稿。
- 投影片文字用英文，字級與現行 deck 一致。
- **三段要等重**。不要把命中的那段畫得比較大、比較亮、或加勾。
  預註冊的重點正是**在看到數字之前三段就一樣重要**；畫成「答對了」會毀掉整頁的論點。
- 圖 A 的誤差橫條**必須**跨過 9；圖 C 的實測點**必須**在帶子外。這兩件是各自那張圖的全部意義。
- 沿用關卡帶那張的色票與圖示語彙（實線＝如註冊、虛線＝較弱且已揭露、斷開＝不存在）。
- 產出後更新模板 §C0-v2 頁序，並註明這幾頁與 p.8 的 `PRE-REGISTERED` band 的分工。
