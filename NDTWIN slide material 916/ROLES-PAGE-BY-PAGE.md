| | |

## 頁 4　ROLE-4　併發雙開

| | |
|---|---|
| **定位** | 第二個人在第一個人還在用的時候動手 |
| **踩哪兩個假設** | 時間（兩件事不會同時發生） |
| **做了什麼** | 兩個 owner 同時 `ndt claim`；外人下 `ndt down`；owner 自己在宣告「正在量測」時下 `ndt down`。**這一輪的受測物就是 claim 本身**，所以特別授權它用第二個身分 |
| **量到什麼** | **2/16**：同一秒兩個 `claim` **都回 rc 0「已取得」**，而檔案只留最後寫的那個——沒有鎖，是一個先查後寫的窗口。偏移 50 毫秒以上就全部正確拒絕（0/9） |
| **另外兩條** | 外人的 `down` 有被擋（2/2），但**它印出來的救援指令貼上去會被 shell 當語法錯誤炸掉**；「正在量測，不要拆」對 **owner 自己的 `down` 零保護**，宣告中的 reader 直接被殺 |
| **被自己推翻** | T3（一條假說沒成立，當場記下來） |
| **後續** | FIX-NDT-3 → merge `a180134f`，七條全部先看過紅 |

**一句話**：兩個人同一秒都被告知「實驗室是你的」。
